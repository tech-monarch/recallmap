# Self-hosted fonts

Latin-subset variable fonts, copied from the `@fontsource-variable/*` packages (SIL Open Font License 1.1; license texts are alongside each font). They replace `next/font/google` so builds need no network access to Google and visitors' browsers do not contact Google Fonts.

| Font | Use | File | Weight axis |
|---|---|---|---|
| Manrope | UI and headings | `manrope-latin-wght-normal.woff2` | 200-800 |
| Source Sans 3 | reading text | `source-sans-3-latin-wght-normal.woff2` | 200-900 |
| JetBrains Mono | code | `jetbrains-mono-latin-wght-normal.woff2` | 100-800 |

Only the Latin subset is included (the same subset the previous Google Fonts configuration requested). Add other subsets here if non-Latin learner content needs them.
